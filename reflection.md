Kiara Sunil Singh- I enjoyed learning about Unit Testing because it's a good way to check if the program is running correctly and identifying where the issues are. However, I did find it challenging to implement since I was confused on what I should be checking specifically and how to use the different assert methods. I found that by using resources such as W3 Schools and GeeksforGeeks I was able to troubleshoot some problems I was having. I worked on the tests for the passenger class and the train class. For the passenger class one test the tests check to ensure that a passenger can correctly board the train. I found it tricky to implement this because the methods in the passenger class did not return specific values so it was hard to compare expected and actual values. So instead I created a boolean variable that returned true if the passenger successfully boarded and false if the passenger could not board, I then used the changes to this variable to check if the method worked correctly. I also used the same logic for the removePassenger test. For the getCar test I checked if the object (car) actually had a reference that was not null, then I checked if the car's capacity was equal to the max capacity to make sure that the car was created and retrieved correctly. For future students I would recommend using all the resources available.
